Langfuse tracing

          
Traces every LLM call (ingestion and retrieval) to a Langfuse project for latency/cost/error monitoring — powers the Dashboard's "Langfuse — last 24h" card and the Monitoring screen. The public/secret key and host are configured in this app's .env file only (LANGFUSE_PUBLIC_KEY / LANGFUSE_SECRET_KEY / LANGFUSE_HOST) — this toggle just turns tracing on or off using whatever is already there; it never sees or stores the keys themselves.

LLM sampling temperature

          
Controls randomness in every LLM call (answer generation and independent evaluation) — lower values (closer to 0) give more consistent, repeatable answers to the same question; higher values (closer to 1) give more varied phrasing. Leave unset to use the active provider's own default. Takes effect on the very next question, no restart needed. Note: GPT's reasoning-effort models don't support an overridden temperature — this setting is silently ignored for those, and the app log says so.

          

            
            
          

          

            
            
            
          

        


        

          
Response format

          
Controls how the LLM structures every /api/ask answer — the sections it must include, extra instructions, and tone. Takes effect on the very next question, no restart needed.

          

            
            
          

          

            
            
          

          

            
            
          

          
          
          
        


        
        

          
Comparative / for-against structure

          
Overrides the response structure whenever a question asks which side prevails — favourable/unfavourable, for/against, comparison, hold/withhold. Applies on top of ANY active prompt (built-in or a System prompt override above), since this is a property of the question, not of the prompt. Takes effect on the very next matching question, no restart needed.

          

            
          

          

            
            
          

          

            
            
          

          
          
          
        


        
        

          
Reranker relevance filter

          
Controls which retrieved chunks are relevant enough to reach the LLM. A chunk scoring below "Minimum relevance" is dropped entirely unless nothing clears that bar, in which case up to "Fallback max chunks" clearing the lower "Fallback relevance" bar are used instead (tagged lower-confidence). "Top N" caps how many chunks are sent either way. Takes effect on the very next question, no restart needed.

          

            

              
              
            

            

              
              
            

            

              
              
            

            

              
              
            

          

          
          
          
        


        
        

          
Graph-expansion routing (KG + RAG)

          
For KG + RAG mode only: when a question matches one of the trigger phrases below (a precedent/status/lineage-type question — "still good law", "overruled", "superseded", etc.), retrieval additionally walks one graph hop from the top matched/vector-retrieved sources across relationship edges (OVERRULES, SUPERSEDED_BY, AMENDED_BY, and similar) to pull in directly connected authorities a similarity search alone would miss. Skipped for other questions to avoid the extra lookup where it wouldn't help. Takes effect on the very next matching question, no restart needed.

          

            
          

          

            
            
          

          

            

              
              
            

            

              
              
            

          

          
          
          
        


        

          
System prompt

          
The full instruction template sent to the LLM for every /api/ask answer — role, grounding rules, and response structure. Overriding this replaces the built-in prompt entirely (the Response format section above is ignored while an override is active, since a custom prompt normally defines its own structure). Takes effect on the very next question, no restart needed.
