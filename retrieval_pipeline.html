How a question becomes an answer

Every call to /api/ask runs the same pipeline: a cache check, an intent classification, two retrieval paths run side by side — one walking the Neo4j graph via an LLM-written Cypher query, the other doing vector similarity search over chunk embeddings — merged, reranked, grounded, and handed to an LLM to write the answer. A second, independent LLM then grades that answer and can trigger one bounded retry with a wider pool of chunks before anything is cached and returned.
